# Strigoi Companion 0.6.0

O Ask/Talk ganhou uma apresentação mais leve e legível. Quando conclui uma
resposta, o Familiar fala um resumo em um balão acima da cabeça; o painel mantém
o texto completo em uma área rolável. O balão limita o trecho exibido para não
cobrir o jogo e permanece mais tempo para respostas maiores.
