# 0.5.5 — Ask/Talk durante gameplay

Ao enviar uma pergunta, o Quick Talk devolve o foco à janela capturada e continua visível sem receber foco. Cancelar sem inferência fecha o HUD. Ask/Talk passa a manter uma única imagem local de 1280×720 para a pergunta atual, enquanto o replay continua na resolução reduzida. O prompt exige transcrição de menu somente quando o texto estiver legível na imagem atual.
