# Strigoi Companion 0.5.9

Cada jogo abre uma run padrão própria, nomeada com o jogo. Runs padrão antigas
chamadas `Run principal` são renomeadas sem perder o Chronicle existente. O
nome do jogo também remove os sufixos técnicos comuns da janela, como resolução
e renderizador, antes de aparecer na run.
