# Familiar Strigoi

Sprites do pet personalizado criado pelo usuário para a feature Pets do ChatGPT. Reutilização solicitada pelo usuário em 12/09/2026. Não são as imagens estáticas da IDE.

Origem: exportação local do pet personalizado Strigoi do ChatGPT, fornecida pelo criador do projeto.
SHA-256 original: 4BD1D2ACED06B773D6398898AEA250F3C00374070613CBEC63FED0A6479A08D0.

PNG convertido sem alteração dos pixels RGBA com Pillow 12.1.1, para leitura WPF sem codec adicional. Original WebP preservado no repositório. Grade 1536 × 2288, 8 × 11, células 192 × 208. Timings são escolhas do novo player e não importação do runtime do ChatGPT.
